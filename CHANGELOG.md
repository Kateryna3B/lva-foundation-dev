# Зміни

## 0.2.4-org2 — 2026-10-07
Оновлено регламент після зупинки S1 через квоту та зовнішньої рецензії Gemini: компактний PROJECT_STATE, послідовний режим за замовчуванням, task/report бюджети, промпти v1.1, рекомендації GitHub/Drive/Docs. Лише документація; remote та cloud runtime не додано, функціональний S1 не виконано.

## 0.2.4-org1 — 2026-10-07
Організаційний пакет, програма залишається 0.2.4. Створено Git baseline, документацію, реєстр проблем, агентні промпти v1.0 та правила приймання. Функціональних змін і міграції БД немає.
