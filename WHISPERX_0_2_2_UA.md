# Foundation 0.2.2: контроль часових меж

Профіль WhisperX залишається large-v3 / CPU / int8 / batch 4. Нічого встановлювати не потрібно.
Розпакуйте окремо, запустіть Run_Tests.bat, потім Start_Foundation.bat та виберіть наявний робочий каталог.
Для порівняння запустіть ту саму пробу 00:00–01:00. Версія контролера створює окремий запуск; попередні результати зберігаються.

Нові прапорці на словах та репліках:
- WORD_DURATION_LONG: тривалість слова понад 1.5 с.
- ALIGNMENT_SCORE_LOW: alignment score нижче 0.5.
- WORD_NEAR_WINDOW_EDGE: початок або кінець слова в межах 250 мс від краю вибраного аудіо.
- WORD_ZERO_DURATION: нульова тривалість слова.

Це евристики для перегляду, а не підтвердження помилок. Межі й текст не змінюються. Прапорці реплік також показуються у TXT/MD.
Alignment require означає успішне виконання alignment, а не ручне підтвердження точності.
Для перевірки останньої фрази використайте окрему пробу до 01:05, щоб не обрізати продовження на хвилині.
Реальний ASR і прослуховування аудіо тут не виконано.
