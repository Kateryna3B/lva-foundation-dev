# Версії промптів

v1.0 — 2026-10-07: створено 5 окремих промптів зі спільними обмеженнями та різними ролями. Враховано read-only рецензію агентної схеми: обмеження паралельності, незалежний QA, непідключений Gemini, evidence-based інтеграція.

Майбутній запис: prompt/version/date/task/defect → зміна формулювання → очікуваний ефект → перевірка на наступній задачі. Не переписувати минулі версії без Git-історії.

Перед випуском v1.0 незалежна рецензія виявила й інтегратор усунув дві суперечності: заборону merge/release у промпті інтегратора та вимогу worktree/implement у Gemini review-only. Початковий невипущений варіант не був дорученням функціонального впровадження.
