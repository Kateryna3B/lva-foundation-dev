# Розгортання й оновлення

Поточний підтверджений сценарій — наявний Windows-ПК із робочим C:\WhisperX\venv. Організаційний пакет не є повним офлайн-інсталятором Python/моделей.

1. Дочекайтеся завершення активних робіт, закрийте попередні вікна. Зробіть штатну резервну копію робочих даних і перевірте її.
2. Розпакуйте ZIP окремо. Коренева папка має назву ZIP без .zip. Код знаходиться в підпапці source.
3. У source запустіть Run_Tests.bat; очікується 58 тестів та OK. Це синтетичні тести; вони не підтверджують ASR/Windows end-to-end.
4. Запустіть source/Start_Foundation.bat. Версія 0.2.4 правильна: org1 змінив організацію, а не програму.
5. Виберіть наявний основний робочий каталог. Не переносіть справи у source. Повторно приймати ті самі матеріали не потрібно.
6. Для наявного WhisperX не запускайте Setup_ASR.bat автоматично: це окремий інсталяційний маршрут. Перевіряйте вибраний Python і модельний кеш.

Встановлені в підтвердженому пілоті версії: Python 3.10.11, WhisperX 3.8.7rc1, faster-whisper 1.2.1, CTranslate2 4.8.1, Torch 2.8.0 CPU, NumPy 2.2.6. Це опис конкретного перевіреного середовища, не універсальна гарантія сумісності. На чистому ПК потрібні підготовлені пакети й моделі; процедура ще не прийнята.

Організаційна редакція не мігрує registry v1. Майбутню миграцію випускати тільки з резервуванням, перевіркою версії та інструкцією відкату. Git не обов’язковий оператору; розробнику див. DEVELOPMENT_UA.md.
