# ADR-001 — План після аудиту та організація

Дата: 2026-10-07. Статус: напрям затверджено користувачем у розмові; конкретна схема агентів нижче — реалізаційна рекомендація інтегратора.

Рішення: зберегти локальний Windows/офлайн процес, незмінні джерела, окремі канали, цілочисельний час від початку оригіналу, явні статуси ASR/alignment/review. Повний файл — штатний режим. Структурно коректне слово не отримує автоматично VERIFIED. Пауза не отримує психологічний висновок за одним порогом. XLSX обов’язковий для завершення первинної мети; Parquet — подальший опційний експорт. Час у мікросекундах — int64. Підтвердження моделей/мов — окреме.

До нових функцій зафіксувати baseline, Git і документацію. Делегувати незалежні задачі; головний агент відповідає за контракти, аудит, інтеграцію та кінцевий випуск. Gemini — зовнішня думка, не джерело автоматичних директив. Процес розробки може використовувати хмарних агентів; офлайн-вимога стосується цільової експлуатації програми.

Причина: повторювані дрібні випуски та неструктурована історія спричинили плутанину. Альтернатива «всі агенти редагують спільний каталог» відхилена через конфлікти. Альтернатива «обов’язкові Parquet та LLM зараз» відкладена через відсутність потреби для найближчого результату.

Наслідки: окремі гілки, обмежені allowlist, один інтегратор, окреме Windows-приймання, журнал промптів. Нова суттєва зміна вимог оформлюється наступним ADR з поясненням, не мовчазним перезаписом цього рішення.
