# Оператор: поточна версія 0.2.4

1. Запустіть Start_Foundation.bat із розпакованої папки. Git для роботи не потрібний.
2. Оберіть ОСНОВНИЙ локальний каталог із registry.sqlite3 та cases. Не обирайте cases/UUID: головне вікно поки може створити там порожній реєстр (K04).
3. «Справи» показує список; вставте відповідний ID вручну. Не використовуйте ID тестової справи для інших матеріалів.
4. Для нових матеріалів: «Чистий бланк» → заповнити/зберегти XLSX → «Приймання». Оригінал і бланк реєструються разом. Точний повтор може повернути наявну справу.
5. Перед «Витягнути канали» підтвердьте, у якому каналі респондент. Змішаний запис потребує окремого маршруту; не називайте його ізольованим stereo.
6. За потреби «Частини»: межі вводяться у часі й покривають запис. Зміна вже створених меж як ревізія ще не реалізована.
7. «Транскрибація»: для перевіреного профілю whisperx / cpu / keep_asr і Python C:\WhisperX\venv\Scripts\python.exe. Мова — відповідна запису або auto; успішний uk не підтверджує готовність ru.
8. Коротка проба вимкнена за замовчуванням: початок/кінець ігноруються. Для фрагмента ввімкніть її й задайте межі до 2 хв.
9. Рухомий індикатор = очікування, PID = процес ще живий; точного відсотка немає. «Зупинити» завершує роботу контрольовано; перевірка кешу може очікувати завершення свого етапу.
10. Після успіху відкрийте TXT. Якщо reused і кнопка не працює (K03), знайдіть transcript_txt із selection=both та потрібним run_id у manifest справи.
11. DRAFT_UNREVIEWED та ALIGNED_UNREVIEWED потребують перевірки. Довгі слова й низький score — кандидати на перевірку, не доказ помилки тексту.
12. Імпорт LVA зберігає raw з неперевіреним часом. Остаточної спільної Excel-таблиці та ручного редактора ще немає.

Не змінюйте архівні UUID-файли вручну. Для відновлення/оновлення див. OPERATIONS_UA.md. Завершення ASR не означає завершення всієї справи.
