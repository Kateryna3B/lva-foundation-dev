# LVA Foundation 0.2.4

ZIP та його внутрішня папка мають однакову назву без розширення: LVA_Foundation_v0_2_4.

## Зміни
- Повний файл — режим за замовчуванням. Коли коротку пробу вимкнено, часові поля неактивні та ігноруються. Початок і кінець вводити не потрібно.
- Рухомий індикатор очікування, загальний таймер, час без зміни етапу, канал, етап, PID дочірнього процесу та шлях до журналу рушія.
- Індикатор і таймер показують, що інтерфейс відповідає. PID повідомляє, що процес ще не завершився. Це не гарантія просування обчислень; точного відсотка рушій не надає.
- На етапі перевірки кешу PID не показується. Зупинка цього етапу очікує його завершення; перевірка має timeout 180 секунд.
- Під час роботи кнопка запуску та перемикач короткої проби блокуються. Завершення й помилка зупиняють індикатор.

## Запуск
1. Дочекайтеся завершення поточної транскрибації перед переходом на нову версію.
2. Розпакуйте ZIP окремо. Запустіть Run_Tests.bat: 58 тестів, OK.
3. Запустіть Start_Foundation.bat; перевірте 0.2.4 у заголовку.
4. Виберіть основну папку з registry.sqlite3 і cases. Введіть ID справи 9b9c9606-f6cd-469f-95cf-4df9137b3716.
5. Відкрийте «Транскрибація». Залиште whisperx / cpu / auto / keep_asr. Коротка проба вже вимкнена: опрацьовується весь файл, обидва канали.
6. Запустіть і спостерігайте етап та таймер. Завершення позначається «Чернетку збережено». Якщо цей запуск уже збережений, контролер може повторно використати результат.

ASR-профіль та версію обчислювального контролера не змінено. Залежності перевстановлювати не потрібно.
