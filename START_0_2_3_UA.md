# LVA Foundation 0.2.3 — виправлення номера версії

Причина: у 0.2.2 заголовки launcher.py і Start_ASR.py містили фіксований рядок 0.2.1. BAT був правильний. Тепер обидва заголовки читають __version__ з lva_system/__init__.py.
ASR-контролер зберігає версію 0.2.2 у відбитку запуску: алгоритм не змінено, повторне використання результатів 0.2.2 залишається можливим.

## Запуск
1. Якщо транскрибація зараз працює, дочекайтеся завершення. Потім закрийте вікна Foundation та ASR.
2. Розпакуйте новий ZIP в окрему папку. Не розпаковуйте його поверх попередньої версії чи робочих даних.
3. У папці LVA_Foundation запустіть Run_Tests.bat. Очікується 54 тести та OK. Це синтетичні тести, вони не запускають WhisperX.
4. Запустіть Start_Foundation.bat. Заголовок має бути «LVA Foundation 0.2.3 — пілот».
5. Натисніть «Обрати каталог» та виберіть основний робочий каталог, у якому розташовані registry.sqlite3 і папка cases. Не вибирайте cases або окрему справу всередині неї.
6. Для наявного тестового запису введіть у поле ID справи: 9b9c9606-f6cd-469f-95cf-4df9137b3716. Кнопка «Справи» показує зареєстровані ID.
7. Натисніть «Транскрибація». Заголовок нового вікна має бути «LVA ASR 0.2.3 — чернетка».
8. Залиште whisperx / cpu / auto / keep_asr, Python C:\WhisperX\venv\Scripts\python.exe. Вимкніть коротку пробу, щоб обробити весь файл.
9. Запустіть обробку. Якщо повний результат 0.2.2 вже є, він може бути використаний повторно — це очікувано.
10. Надішліть підсумок запуску та JSON обох каналів.

Встановлювати ASR-пакети чи повторно реєструвати справу не потрібно. Прапорці 0.2.2 збережено; ця версія не виправляє часові межі автоматично.

Перевірка розробника: синтетичні тести Linux, синтаксис Python 3.10, заголовки обох вікон, контрольні суми ZIP. Вікна на Windows і реальний ASR тут не запускалися.
